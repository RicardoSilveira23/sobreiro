# Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sobreiro's docs site (a home page and a manual) in `site/`, its pictures drawn by the app, a check script, and a Pages workflow that stays off until the repo is public.

**Architecture:** Hand-written static HTML and CSS in `site/`, no build. The app gains `--snapshot-site <folder>`, which draws the site's four pictures at 2x from a fixed sample reading defined in Core. A Node script with no dependencies checks the pages; a Pages workflow runs it on PRs and deploys `site/` from `main` once the `PAGES` variable is `true`.

**Tech Stack:** C# / .NET 10 (WPF, xUnit), HTML and CSS, Node 22 (`node:test`), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-09-site-design.md` (read it first). The picked look is `docs/candidates/site/index.html`, variant B: reuse its CSS.

## Global Constraints

- No request to another host from any page: fonts, CSS, JS and images are all under `site/`. Links to other sites are fine.
- All links in `site/` are relative, so the pages work locally and under `/sobreiro/` on Pages.
- Tokens: `site/assets/foundation.css` is a copy of the design system's `tokens/foundation.css`, without the other projects' tile colours. Sobreiro's own tokens live only in `site/assets/sobreiro.css`: `--sobreiro-text: #a594ff` (dark) / `#5a3dd1` (light), `--on-sobreiro: #fff`. No raw colours, sizes or radii in `site.css` beyond what the candidate already uses; no `--red` anywhere.
- Voice: short, plain, sentence case, Ricardo's first person where a person speaks. Labels are plain (no capitals, no letterspacing) except Unbounded headings. No full stop on a heading. Every fact from `README.md`, `docs/plan.md`, the release design (`C:\Dev\openheadroom\.claude\worktrees\inspiring-wilbur-af4c07\docs\superpowers\specs\2026-11-09-release-workflow-design.md`) or the code.
- Never on the site: GitHub Copilot, the 5-hour-only option, a version number, a licence claim, the reason behind the name beyond "the Portuguese name of the cork oak, whose trunk in section is the tray's two rings", any token or `.credentials.json` content.
- Motion: only Night's 1 (lettering settles in, .7s, 8px rise, `--ease`), 2 (theme fade .25s), 6 (sun or moon turns 20°, .25s on hover), 7 (button arrow 4px forward, .18s), all inside `@media (prefers-reduced-motion: no-preference)`. Pages are complete without script.
- Phone: 16px gutters under 720px (`.wrap { width: calc(100% - 32px) }`); no sideways page scroll at 390px.
- C#: `dotnet build -c Release` with warnings as errors, and `dotnet test`, both pass after every C# task. Logic outside drawing goes in `Sobreiro.Core` with an xUnit test.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **In-page and cross-page fragments** (`manual/#limits`, the manual's contents links): a reader expects each to land on its section. Pinned by the check's fragment test in Task 3.
- **The theme switch against the system theme**: the flyout and strip shown must match the page's theme in all four cases (system dark or light, switch pressed or not). Pinned by Task 4's captures in both themes with and without `data-theme`.
- **Long code lines on a phone** (the manual setup JSON with a full path): the page must not scroll sideways; the code block scrolls inside itself. Pinned by Task 5's 390px capture with `pageWidth == innerWidth`.
- **Re-running `--snapshot-site`** on an unchanged app: no PNG changes, or every refresh is noise in git. Pinned by Task 2's run-twice-and-compare step.
- **The alt text drifting from the picture**: the alt text quotes the drawn strings. Pinned by Task 1's `SampleReading` tests, which fix those strings.
