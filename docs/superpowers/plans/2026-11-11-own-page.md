# Sobreiro's own page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the landing page and the manual in Sobreiro's own look, and drop the shared
stylesheet the site was built on.

**Architecture:** Plain HTML, CSS and a little script in `site/`, no build step. One stylesheet
for the look and the landing page, one for the manual's parts, one script per page. Node's own
test runner pins what the design fixes.

**Tech Stack:** HTML, CSS, vanilla JS, `node --test` (Node 22). No packages added.

**Spec:** [docs/design.md](../../design.md). Read it whole before any task. Every colour, size,
motion and word comes from it.

## Global Constraints

- Colours: only the two lists in the spec. Hex values are written once, as custom properties on
  `:root` in `site/assets/site.css`: `--bg #ebe6ff`, `--ink #1d1447`, `--soft #4d457c`,
  `--v #6f4df6`, `--vt #5a3dd1`, `--on #ffffff`, `--line #b9adf5`, `--box #f6f3ff`,
  `--tb #1c1c1c`, `--dim #9a9a9a`, `--purple #a594ff`, `--amber #ffb020`, `--red #ff6b6b`.
  Elsewhere only `var(--…)`, or `rgba(255, 255, 255, a)` and `rgba(111, 77, 246, a)`.
- Faces: Sora, Inter, Unbounded, JetBrains Mono, each one `@font-face` from
  `site/assets/fonts/*-latin-wght-normal.woff2` (the four files are there). Nothing loads from
  another host.
- Light only: no `prefers-color-scheme`, no `data-theme`, no theme switch.
- No `vh`, `svh`, `dvh` or `lvh` unit anywhere: the page never stretches to the window.
- All content is in the HTML. Script only steps the pill and drives the manual's switches.
- Every link and button is at least 44 px tall.
- Every `animation` sits inside `@media (prefers-reduced-motion: no-preference)`.
- Words are copied from the spec's "The words" table, and the manual's words are not changed.
- Nothing written here (files, commit messages) names or links another repository or project,
  beyond the links the pages already carry.
- `npm run check` passes at the end of every task.

## Review Focus

Conditions no test here exercises; look at them rendered.

- 320 px wide: nothing scrolls sideways; the pill and the two address boxes still fit.
- 700 to 999 px wide: one column, the diagram centred at 490 px at most.
- 1000 px exactly and 1920 px: two columns; the last step ends level with the diagram's bottom.
- Half way through a step (about 4.3 s into a loop): no figure jumps or shifts its neighbours.
- Keyboard: every link and button shows the focus outline, in reading order.
